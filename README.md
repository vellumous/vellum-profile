# vellum

small, careful web things. no frameworks. no build step. just html, css, js — and the occasional node script that earns its keep.

i care about:
- the web as a set of *materials* (html/css/js), not a platform to be abstracted away
- sites that feel hand-made, even at scale
- offline-first: your site should work when the network doesn't
- the 90s/2000s web, where every page had a *point of view*
- code that's short enough to read in one sitting

this is a working profile. most of the interesting stuff is private (client work, in-progress). what's here is the part i'm happy to show.
